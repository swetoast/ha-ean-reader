# EAN Reader Integration

Scan barcodes and automatically manage your Home Assistant shopping list using OpenFoodFacts database.

## Quick Start

1. **Before Installing**: Fill out the [OpenFoodFacts API usage form](https://docs.google.com/forms/d/e/1FAIpQLSdIE3D8qvjC_zRJw1W8OmuHhsWJ_NSckiiniAHlfaVwUZCziQ/viewform)
2. Install via HACS
3. Add integration in Home Assistant
4. Enter your contact email
5. Start scanning barcodes!

## Features

- 📱 Barcode scanning with mobile app
- 🛒 Auto-add to shopping list
- 🗄️ Local product database
- 🌍 OpenFoodFacts integration
- 📊 Statistics tracking
- 💰 Optional price tracking
- 📅 Optional expiry tracking

## Requirements

- Home Assistant 2024.1.0+
- Shopping List integration (optional, for auto-add feature)
- Mobile app for barcode scanning
- Internet connection for OpenFoodFacts lookups
